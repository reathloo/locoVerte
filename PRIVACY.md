# locoVerte – Privacy Policy / Datenschutzerklärung

Last updated: 13 October 2026 / Stand: 13. Oktober 2026

## English

locoVerte processes selected files on your device. It does not upload file contents to a locoVerte server, create an account, collect analytics, or transmit telemetry. The extension has no backend service. Conversion libraries are bundled with the extension and are not loaded from a remote host at runtime.

The language and appearance preferences are stored locally in your browser. Selected files and results are held in browser memory while the extension window is open; downloads are saved through the browser to the location you choose. locoVerte does not retain a copy of your files after the window is closed.

If you explicitly choose “Use in upload field,” locoVerte inserts a processed file into a file input on the website from which you opened the extension. That website may upload the file immediately or when you submit its form. The website’s own privacy policy then applies. locoVerte does not send the file directly.

The `activeTab` and `scripting` permissions are used only for that optional, user-initiated upload-field action. The extension does not request continuous access to all websites.

## Deutsch

locoVerte verarbeitet ausgewählte Dateien auf deinem Gerät. Dateiinhalte werden nicht an einen locoVerte-Server hochgeladen. Es gibt weder Benutzerkonten noch Analyse- oder Telemetriedaten. Die Erweiterung hat keinen Backend-Dienst; alle benötigten Konvertierungsbibliotheken sind im Add-on enthalten.

Sprache und Farbschema werden nur lokal im Browser gespeichert. Ausgewählte Dateien und Ergebnisse liegen während des geöffneten Erweiterungsfensters im Browserspeicher. Downloads speichert der Browser an dem von dir gewählten Ort. Nach dem Schließen des Fensters behält locoVerte keine Kopie der Dateien.

Wenn du ausdrücklich „In Upload-Feld einsetzen“ auswählst, setzt locoVerte das Ergebnis in ein Dateifeld der zuvor geöffneten Website ein. Diese Website kann es sofort oder beim Absenden des Formulars hochladen; dann gilt deren Datenschutzerklärung. locoVerte lädt die Datei nicht selbst hoch.

Die Berechtigungen `activeTab` und `scripting` dienen nur dieser optionalen, von dir gestarteten Aktion. Ein dauerhafter Zugriff auf alle Websites wird nicht angefordert.
